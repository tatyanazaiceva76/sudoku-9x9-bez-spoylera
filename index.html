Проверьте судоку, не открывая ответ

Вставьте девять строк по девять клеток. Страница найдёт повторяющиеся цифры в строках, столбцах и квадратах 3×3. Проверка работает в вашем браузере: сетка никуда не отправляется.

Проверить сеткуЧетыре бесплатных судоку A4

Введите сетку

Цифры 1–9 — заполненные клетки; точка или 0 — пустая клетка. Пробелы и вертикальные черты между клетками допустимы. Вставьте девять строк по девять клеток либо все 81 клетку подряд одной строкой. Как перенести судоку с бумаги.

Результат появится после проверки.

Что именно проверяется

  1. Каждая из девяти строк.
  2. Каждый из девяти столбцов.
  3. Каждый квадрат 3×3.
Важная граница: даже сетка без повторов может не решать вашу задачу. Здесь не сравниваются исходные подсказки, не проверяются единственность решения и логика ходов. Для полной сверки используйте ответ к своей задаче.

Клетки с повторами подсвечиваются после проверки. Страница не хранит введённую сетку между открытиями.

Если нашёлся повтор

Проверьте одну цифру за раз

Смотрите на подсвеченные клетки и указанные строки, столбцы или квадраты. Повтор в одной строке иногда даёт ещё и повтор в квадрате — это один ввод, обнаруженный двумя правилами.

Не исправляйте исходные числа

Перед заменой цифры найдите её в исходной задаче. Если это напечатанная подсказка, вернитесь к своим ходам; если это ваш ответ, проверьте кандидатов для этой клетки.

Нужна ручная проверка на бумаге? Три прохода по решённому судоку и пример ошибки.

Хотите ещё задачи для печати?

Начните с четырёх бесплатных судоку A4 с ответами. Если такой формат подходит, на Маркете есть цифровой сборник из 200 судоку четырёх уровней. Цену, наличие и способ получения проверяйте в карточке перед покупкой.
